# mbround18 repo coverage

A tracker for `paws` adoption across `mbround18`'s public repos, generated by
querying `gh api`/`gh search code` for `paws-up`, `mbround18/paws`,
`gh-reusable`, and `dagger` references in each repo's
`.github/workflows/*`. Snapshot: **2026-08-19**. Public repos only; 23 more
public repos have no `.github/workflows` at all (docs/config/one-off repos)
and are omitted below, along with 4 archived repos
(`arkrb`, `POS409-learning-team-1`, `url_shortener`, `image-to-tile`,
`gamer-drop-zone`).

Regenerate by re-running the same `gh api repos/mbround18/<repo>/contents/.github/workflows`
+ per-file content grep this file was built from — nothing here is hand-maintained
beyond the status/note column.

## Infra, not coverage candidates

- [gh-reusable](https://github.com/mbround18/gh-reusable) — the TS system `paws` is replacing. Its own CI naturally still uses itself.
- [gh-reusable-docker-testing](https://github.com/mbround18/gh-reusable-docker-testing) — a test fixture for `gh-reusable`, not a real project.
- [paws](https://github.com/mbround18/paws) — this repo. Uses its own `paws-up`/`paws ci`/`paws release` to build and ship itself (see [`docs/DEVELOPMENT.md`](./DEVELOPMENT.md)).
- [paws-helm-publish-test](https://github.com/mbround18/paws-helm-publish-test) — throwaway fixture used to verify `paws helm --publish` against a real GitHub Pages index; no CI of its own.
